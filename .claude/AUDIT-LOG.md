# Session audit log

Append-only, durable record of exactly what a freshly-spawned Claude
instance in this project will see (the boot-read chain) plus a sha256 of
every file that chain depends on. Never edit past entries — the log's
value IS its history. Generated by `bin/crt-session-audit.sh`
(`bash bin/crt-session-audit.sh` to append a new block, `... verify` to
diff current file hashes against the most recently recorded block and
flag drift).

This exists because of a real incident earlier 2026-07-21: a stale env var
in `~/.bash_profile` silently broke STT across every reboot for who knows
how long, and nobody could tell because nothing was actually checking
whether the files a fresh boot depends on had drifted from what was
documented. `verify` turns "I assume this is still true" into "I checked."
